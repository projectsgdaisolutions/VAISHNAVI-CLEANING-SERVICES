# Vaishnavi Glass Cleaning Service — 5-page website

This build keeps the supplied reference UI's navy/white/lime visual style, typography, rounded cards, header, footer and floating WhatsApp button, and restructures the site into five separate pages:

- Home (`/`)
- About Us (`/about`)
- Our Services (`/services`)
- Gallery (`/gallery`)
- Contact Us (`/contact`)

The design is image-first: each page starts with a large visual banner, followed by a short heading and concise copy. The booking form and service enquiry links open WhatsApp at +91 8007947113 with the visitor's details.

## Run locally
```bash
npm install
npm run dev
```
Open the Vite URL shown in the terminal.

## Build
```bash
npm run build
```
