# ✨ Vaishnavi Glass Cleaning Service

**Clean Spaces. Healthy Life.**

A modern, responsive, and user-friendly website for Vaishnavi Glass Cleaning Service, designed to showcase professional cleaning services and make customer enquiries and bookings simple through WhatsApp.

## 🌐 About the Project

Vaishnavi Glass Cleaning Service is a five-page business website built with React and Vite. It provides customers with information about cleaning services, a visual gallery, company details, and a convenient WhatsApp booking experience.

## 📄 Website Pages

1. **Home** – Introduction, featured services, and before-and-after examples.
2. **About Us** – Business introduction, service philosophy, and highlights.
3. **Our Services** – Details of available cleaning services.
4. **Gallery** – Visual showcase of cleaning services and illustrative examples.
5. **Contact Us** – Contact information and an interactive booking enquiry form.

## 🚀 Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/projectsgdaisolutions/VAISHNAVI-CLEANING-SERVICES.git
```

### 2. Navigate to the Project Folder

```bash
cd VAISHNAVI-CLEANING-SERVICES/vaishnavi-cleaning-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

## 📱 WhatsApp Integration

The website includes three WhatsApp contact options.

Customers can:
- Choose their preferred WhatsApp contact.
- Submit their name and location.
- Select a cleaning service.
- Provide a preferred booking date.
- Add additional requirements.

After submitting the form, the website opens WhatsApp with a pre-filled enquiry message.

Contact numbers and WhatsApp links are configured in `src/main.jsx`.

## 🖼️ Gallery and Visuals

The website includes service images, business branding, and before-and-after visual examples.

**Note:** Before-and-after examples are illustrative visuals and should not be interpreted as verified customer project results.

## 🔒 Project Architecture

This is a frontend-only website.

- No backend server is required.
- No database is currently connected.
- Booking enquiries are initiated through WhatsApp.
- Customer form information is not stored in a project database.
